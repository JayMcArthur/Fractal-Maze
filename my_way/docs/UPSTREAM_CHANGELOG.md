Reviewed October 9–10, 2026. [Exact source commits and dates](../../upstream_sources/manifest.json) and [integration details](UPSTREAM_REFRESH.md) remain available. “No newer change” means the refreshed source matched the installed copy; it does not mean the program has no useful features.

Additional README discoveries: [Backlot](https://puzzles.mit.edu/2020/puzzle/backlot/) now has native room/dot/count constraints and a checked 337-move tour. [Omeometo’s image](https://omeometo.hatenablog.com/entry/2018/12/28/155549) exactly matches the existing block pattern; attribution and a checked depth-five replay were added. [The 2026 MIDTERM paper](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.FUN.2026.9) is linked on Home; its algorithm is not claimed as an app feature.

Original local programs were not reset or merged. [Product flows](PRODUCT_FLOWS.md), [solution coverage](../src/data/manifests/solution-coverage.json) and [screenshots](screenshots/flows/index.html) give the app-side review trail.
